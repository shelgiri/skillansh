Progressive Four-Course Learning Pathway

Structured 4-Stage Pathway: ADHAAR → DRISHTI → PRAVAH → BODH

Each programme in this four-course pathway builds systematically upon the previous stage—from clean spreadsheet architecture and executive MIS reporting to multi-source data transformation and interactive business intelligence.

Pathway Course 01 Level: Foundation to Intermediate

ADHAAR – Excel Foundation

Build a rock-solid foundation in structured spreadsheet design. Move from basic data entry to mastering modern lookup functions, conditional calculations, dynamic arrays, and Pivot Table analysis for reliable daily workbooks.

Key Learning Outcomes:
  • ✔ Design normalized, error-resistant data tables with custom validation rules.
  • ✔ Apply 25+ core functions including XLOOKUP, INDEX/MATCH, IF/IFS, SUMIFS, and Dynamic Arrays.
  • ✔ Construct multi-dimensional Pivot Tables and summary schedules from raw transactional logs.

Pathway Course 02 Level: Intermediate

DRISHTI – MIS & Dashboards

Transform raw operational, financial, sales, and inventory logs into automated Management Information System (MIS) reports and clear 1-page visual Excel dashboards equipped with built-in audit checks.

Key Learning Outcomes:
  • ✔ Build automated monthly MIS packs covering variance analysis, ageing schedules, and KPI tracking.
  • ✔ Implement Maker-Checker reconciliation flags to detect data discrepancies automatically.
  • ✔ Design interactive 1-page Excel dashboards using form controls, slicers, and dynamic charts.
View Pricing
Pathway Course 03 Level: Intermediate to Advanced

PRAVAH – Power Query

Eliminate repetitive manual copy-pasting and data cleaning. Learn how to connect folders, ERP exports, and multi-sheet workbooks into automated, 1-click refreshable data transformation pipelines.

Key Learning Outcomes:
  • ✔ Consolidate multiple CSVs, folders, and multi-tab Excel workbooks automatically.
  • ✔ Unpivot cross-tabulated reports, split messy columns, and standardize inconsistent dates/text.
  • ✔ Perform multi-table Merge joins for automated cross-ledger and invoice reconciliations.
View Pricing
Pathway Course 04 Level: Advanced

BODH – Power BI & AI

Master modern Business Intelligence and structured AI workflows. Connect data models in Power BI, write essential DAX calculations, design executive visual dashboards, and use structured Prompt Engineering to accelerate analysis.

Key Learning Outcomes:
  • ✔ Build star-schema relational data models and write DAX measures (CALCULATE, SUMX, Time Intelligence).
  • ✔ Publish interactive Power BI dashboards with drill-downs, KPI cards, and dynamic slicers.
  • ✔ Apply structured Prompt Engineering frameworks to generate and audit complex formulas, DAX, and analytical summaries.

Separate Standalone Specialized Programme

Standalone Specialized Course: KRIYA – VBA & Automation

KRIYA is offered strictly as a separate standalone programme (independent of the four-course learning pathway) for professionals who want to build custom 1-click macro buttons and automate repetitive workbook tasks inside Excel.

Standalone Programme (Separate from 4-Course Pathway) Level: Intermediate to Advanced

KRIYA – VBA & Automation

A dedicated standalone automation course focused on Visual Basic for Applications (VBA) in Excel. Learn how to record, customize, and write clean macro procedures to put repetitive multi-step formatting, sheet splitting, and batch PDF generation onto a single 1-click button.

Key Learning Outcomes:
  • ✔ Record, edit, and structure reusable VBA subroutines, variables, loops, and conditional blocks.
  • ✔ Build 1-click worksheet buttons to split master data into branch/party sheets and export automated PDFs.
  • ✔ Design custom data-entry UserForms with input validation and automated error-handling routines.
